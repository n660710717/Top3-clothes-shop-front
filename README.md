# Clothing Hub หน้าบ้าน

หน้าร้าน React เรียก API ของ `Top3-clothes-shop-back` ที่พอร์ต 8080

## สิ่งที่แก้เพื่อเชื่อมหลังบ้าน

### ที่อยู่ API

เพิ่มไฟล์ `.env` ที่รากของหน้าบ้าน

```env
REACT_APP_API_URL=http://localhost:8080
```

`src/api/backend.js` ต่อที่อยู่นี้หน้าทุก path เช่น `http://localhost:8080/api/products` ถ้าไม่ตั้งค่า เบราว์เซอร์จะยิงไปที่ `localhost:3000` ซึ่งเป็นตัวหน้าบ้านเอง หลังแก้ไฟล์นี้ต้องหยุด `npm start` แล้วรันใหม่

หลังบ้านอนุญาต origin `http://localhost:3000` ไว้ใน `ALLOWED_ORIGINS` แล้ว

### เลิกใช้บัญชีและสินค้าจำลอง

เดิมหน้าล็อกอินเทียบรหัสกับ `localStorage` ชื่อ `app_users` แล้วเก็บโทเคนปลอม `auth-token-...` หน้าร้านจึงคุยกับหลังบ้านไม่ได้

ตอนนี้

- เข้าสู่ระบบเรียก `POST /api/auth/login` แล้วเก็บ JWT จริงใน `localStorage.token` และข้อมูลสมาชิกใน `localStorage.user`
- `AuthContext` ใช้คีย์สองตัวนี้ชุดเดียวกันกับแถบเมนู หน้าผู้ขาย และหน้าแอดมิน
- สมัครสมาชิกเรียก `POST /api/auth/register` ส่ง `email`, `password`, `displayName` และ `role`
- เลือกได้เฉพาะ `buyer` หรือ `seller` หลังบ้านไม่ให้สมัครเป็น `admin` จากฟอร์มนี้
- รหัสผ่านต้องยาวอย่างน้อย 8 ตัวอักษร ตามกฎของหลังบ้าน
- เปลี่ยนรหัสผ่านที่โปรไฟล์เรียก `PUT /api/me/password` พร้อมโทเคน ไม่ได้แก้รหัสในเบราว์เซอร์
- รายการสินค้าและรายละเอียดสินค้ามาจาก `GET /api/products` และ `GET /api/products/{id}` ถ้าหลังบ้านไม่ตอบ หน้าแรกจะแสดงข้อความเชื่อมต่อไม่ได้ และหน้ารายละเอียดจะบอกว่าไม่พบสินค้า
- แดชบอร์ดแอดมินโหลดสมาชิกจาก `GET /api/admin/members`
- ลบสินค้าของผู้ขายถ้า API ตอบไม่สำเร็จ จะไม่ลบการ์ดออกจากหน้าจอ

ลบชุดสินค้าจำลอง 150 ชิ้นและบัญชีเริ่มต้นในไฟล์หน้าบ้านออกแล้ว ข้อมูลชุดนั้นอยู่ในฐานข้อมูลของหลังบ้าน

### บัญชีที่มีในฐานข้อมูล

| อีเมล | รหัส | บทบาท |
|---|---|---|
| admin@clothinghub.com | Admin1234! | admin |
| somchai@seller.com | Seller1234! | seller |
| buyer@store.com | Buyer1234! | buyer |

ผู้ขายเท่านั้นที่ลบสินค้าได้ ผู้ดูแลเท่านั้นที่ดูและเปลี่ยนบทบาทสมาชิกได้

## วิธีเปิด

เปิดฐานข้อมูลและ API ก่อน แล้วค่อยเปิดหน้าบ้าน คนละหน้าต่าง

```powershell
cd c:\Project\Top3-clothes-shop-back
docker compose up -d

cd c:\Project\Top3-clothes-shop-back\clotesShop
go run .
```

```powershell
cd c:\Project\Top3-clothes-shop-front
npm install
npm start
```

หน้าบ้านอยู่ที่ http://localhost:3000 API อยู่ที่ http://localhost:8080

ถ้าแก้โค้ดหลังบ้านขณะ `go run .` ยังทำงานอยู่ ต้องหยุดแล้วรันใหม่ ไม่งั้นเส้นทางสมัครสมาชิกและเปลี่ยนรหัสผ่านจะยังเป็นของเดิม

## สิ่งที่ยังอยู่ฝั่งเบราว์เซอร์

หลังบ้านยังไม่มี API ของส่วนนี้ หน้าบ้านจึงยังเก็บเอง

- ตะกร้าสินค้า
- รายการที่ชอบ
- รีวิวบนหน้ารายละเอียดสินค้า
- คำร้องเรียน
- คำสั่งซื้อของผู้ซื้อและเลขพัสดุของผู้ขาย
- การเพิ่มและแก้ไขสินค้าในฟอร์มของผู้ขาย
- คำขอเปิดร้านและคอมเมนต์ในแดชบอร์ดแอดมิน นอกจากรายชื่อสมาชิก
